This policy explains what the official Z# website and software communicate, what stays on your device, and which outside services are involved.

ON THIS PAGE ScopeWebsiteUpdates Local dataThird parties RetentionYour choicesContact
01

Scope

This policy applies to the official Z# website, Z# Virtual Machine (ZVM), bootstrap installer, automatic updater, and Z# Hub provided by ZombieOS. It does not govern apps, games, packages, websites, or services created by independent Z# developers.

02

Website information

The Z# website does not provide user accounts, advertising, analytics scripts, contact forms, or first-party tracking cookies. ZombieOS does not intentionally collect names, email addresses, or other personal details merely because someone visits the site.

The site is hosted using GitHub Pages. GitHub records visitors' IP addresses for security and may process ordinary request information such as the requested page, time, browser, and referring page under the GitHub Privacy Statement.

03

ZVM downloads and updates

The installer and updater contact www.zsharp.zombieos.com to request the current release manifest and download verified ZVM files. The request identifies the installed Z# version and operating-system family so the service can return the appropriate update. No Z# account, advertising identifier, project source code, or unique device identifier is sent by the updater.

On Windows, the update agent can run at sign-in and check periodically while active. A normal web request necessarily exposes network information such as an IP address to the hosting provider. Downloading the optional test app or game occurs only when the user chooses its download.

Update control. The Windows update agent can be exited from its system-tray menu and disabled from the operating system's Startup Apps settings.
04

Information stored locally

The Z# Hub keeps its installed-project list, package locations, playtime, and last-played information on the user's device. Z# does not transmit that Hub information to ZombieOS. Project source files, compiled packages, and text entered into an app remain local unless that app or its developer explicitly implements an outside service.

05

Third-party projects and links

Z# projects may include independent dependencies or connect to outside services. Those projects and services are responsible for their own privacy practices. Links to ZombieOS, Discord, GitHub, and other websites take visitors to services governed by their respective policies.

06

Retention and security

ZombieOS does not maintain a separate database of Z# website visitors. Information stored locally by the Z# Hub remains until the project is forgotten, its data is removed, or Z# is uninstalled. Hosting-provider security logs are retained and protected according to the provider's policies.

07

Your choices

You may use the documentation without installing Z#. You may exit or disable the update agent, remove locally registered projects from the Hub, and uninstall Z# or a packaged project. Browser privacy controls can manage any storage created by external websites.

08

Questions and changes

Questions about this policy can be sent to jack.johnson@zombieos.com. Material changes will be posted on this page with a revised effective date.
