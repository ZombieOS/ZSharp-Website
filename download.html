ChromeOS can use the Linux build only when its Linux development environment and a way to run Linux commands are available. ChromeOS no longer supports installing .deb files through Files, so this is not a no-terminal installation. School administrators may disable Linux. App and game compatibility varies by Chromebook. Linux builds target glibc-based Intel/AMD 64-bit and ARM64 systems. Early installers are not yet code-signed, so Windows SmartScreen or macOS Gatekeeper may show an unknown-publisher warning.
